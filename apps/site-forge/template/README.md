## Assets (local ComfyUI)

```bash
# from site-forge (webcules-inc/apps/site-forge)
forge generate --project {{FORGE_NAME}} --manifest     # run all jobs in forge.assets.json
forge edit --project {{FORGE_NAME}} --image public/assets/hero.png --prompt "make it dusk" --out hero-v2
```

Hero autodetects media in this order: `public/assets/hero.mp4` → `public/assets/hero.png` → CSS mesh.

## Build & deploy

```bash
pnpm build        # static output in dist/
npx wrangler deploy   # Cloudflare Workers (first time: npx wrangler login)
```

SSR is available if needed: add `export const prerender = false` to a route (Cloudflare adapter is preconfigured).
