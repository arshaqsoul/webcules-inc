# Storyboard: PP-012 - Client RAW handoff is an expiring file-transfer link

Pain point: PP-012
Persona: wedding photographer emailing client RAWs through WeTransfer-style links and hoping they arrive
Tier shown: free
Format: desktop
Seed: 12
Target length: 20-30 s

## Hook (first 1.5 s)

On-screen text (6 words or fewer): RAW handoff, no file-transfer links
Why it stops the scroll: the first frame is the project files drop zone with RAW files waiting, the exact files that never fit in an email and die on a transfer link.
No logo in the first frame.

## Starting state

Fixture to seed (through the app UI and the app's own APIs, nothing by hand in the database):
- The demo org "Amara & Oak Photography" on the Free plan with the wedding project "Willow Creek Estate Wedding" and its seeded client row pointed at `client@example.com` (the operator flips the seeded client email before the take and restores it after, the same class of environment plumbing as PP-010).
- Two or three small RAW files (.cr3 / .arw, a few MB each) ready in the take's local upload folder. The upload happens on camera.

Screen the recording opens on: `/dashboard/projects/{id}` files tab, the drag-and-drop upload zone.
Account and org: the demo studio owner session on the Free plan (so the 3 GB RAW trial pocket is the honest on-screen state).
Recording target note: recorded against the local production-shape dev server (`GROWTH_STAGING_URL=http://localhost:5173`, same code as staging), because the gallery OTP code email is captured to disk on the local target and never delivered - the PP-010 precedent. A staging re-record is possible only if staging gains an email capture; until then the client leg runs local.
This take sends email (the gallery OTP code to `client@example.com`), so the safe-recipient guard applies and `sendsEmail = true`.
Teardown:
- The operator restores the seeded client email. The client's gallery session is the demo client's own and is harmless. The uploaded RAWs stay (they feed later cold-storage states) or are deleted through the UI if the org is being reset.
