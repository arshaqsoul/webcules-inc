# Storyboard: PP-014 - A photographer's brand stops at the gallery page footer

Pain point: PP-014
Persona: studio owners whose logo lives in one corner while every favicon, email and shared link still says the platform's name
Tier shown: studio
Format: desktop
Seed: 14
Target length: 20-30 s

## Hook (first 1.5 s)

On-screen text (6 words or fewer): One logo, branded everywhere
Why it stops the scroll: the first frame is the white-label checklist with the "Generate brand assets" button - the promise that one upload covers favicon, email header, share card and watermark.
No logo in the first frame.

## Starting state

Fixture to seed (through the app's own UI and APIs, nothing by hand in the database):
- Open `/dashboard/settings/brand` as the org owner. The page must show the white-label checklist; if the account is not white-label entitled, the page shows the Studio upsell instead: STOP with "FIXTURE STOP: staging org is not white-label entitled (Studio)".
- The take films a real logo upload, so the fixture requires a clean "No logo yet" start. If a logo already exists there is no delete endpoint: STOP with "FIXTURE STOP: this org already has a logo - use a fresh org or reset it by hand".
- The fixture writes a small synthetic studio-mark PNG (a plain-color wordmark block, no real brand) to `growth/assets/PP-014/logo.png`; the take hands that file to the real file chooser.
- Generation runs automatically after the upload (settings-brand calls generateAndUploadBrandAssets on logo save when white-label entitled).

Screen the recording opens on: `/dashboard/settings/brand`, the white-label card with its 3-step checklist.
Account and org: the staging demo org, owner login, programmatic.
Recording target: staging (`GROWTH_STAGING_URL=https://staging.snaphq.app`).

Teardown:
- None possible without a delete endpoint for brand assets: generation is idempotent and overwrites the same bundle, so a re-run on a fresh state is safe and a repeat run needs the fixture reset described above.

## The payoff shot

Step 4: the status "Brand assets generated - favicon, share cards and email header updated.", focused tight and held while the camera pushes in.
It proves the fix: one logo upload becomes the whole kit - favicon, apple-touch icon, email header, OG share card and watermark source - generated in the browser, without touching an image editor.
